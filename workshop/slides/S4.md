# Rare events break your favorite metric

Deterioration base rate tonight: **18%**. For rare-ish events, AUC flatters:

- **PR-AUC** — precision against recall; punished hard for false alarms; compare it to the **base rate**, not to 1.0
- **Capture@decile** — of all true deteriorations, how many sit in your top-10% riskiest? A working watchlist is a *short list*
- A relationship manager can call 800 accounts, not 8,000 — **the decile is the product**

> Write down your S2 instinct: what AUC would make you proud tonight?

# Two escalations, two legitimate answers

The reference build hit a noise-capped target **twice**:

| | EWS (deterioration) | Line increase |
|---|---|---|
| Oracle said | ceiling ≈ 0.70 | ceiling ≈ 0.71, model ≈ 0.66 |
| Target consumed downstream? | **Yes** — don't touch the data | **No** — pure leaf, last draw |
| Resolution | **Option B: honest gate** (capture + PR-AUC; AUC reported, ungated) | **Option A: sharpen the DGP**, hash-prove every other column unchanged, **keep the gate** |

**The decision tree:** is the target a *pure leaf*? Then a surgical data fix, with proof of isolation, is legitimate. Consumed by others? The data is load-bearing — set an honest gate instead.

> Either way: **escalate to a human, in writing. Never silently weaken a gate. Never silently regenerate data.**
